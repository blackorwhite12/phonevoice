# 手机语音输入 → Mac（初始命令行版本，存档）

> 这是 2026-08-24 存档的“双击 start.command 即可使用”的初始版本。
> 新开发的电脑端 App（主目录 dist/语音输入电脑.app）发布后，本目录保持独立可用。
> 用法与下方一致，端口可通过 `./.venv/bin/python server.py 9000` 自定义。

手机语音输入，文字直接出现在 Mac 当前光标处（比如 Codex、微信、任意输入框），
中间不用复制粘贴。

原理：Mac 上运行一个小服务，手机浏览器打开服务页面后，用手机输入法
（讯飞、豆包、搜狗、自带输入法等）语音说话，识别完的文字自动通过局域网
发到 Mac，Mac 再模拟键盘输入到当前聚焦的应用里。

## 快速开始

1. 双击 `start.command`（首次运行会自动装好依赖）。
   如果 macOS 提示无法打开，右键 → 打开，或改用终端运行：
   `bash start.command`
2. 首次使用需要授予“辅助功能”权限，否则 Mac 无法模拟键盘输入：
   系统设置 → 隐私与安全性 → 辅助功能 → 勾选你启动本程序的 App
   （从终端启动就勾“终端”，双击运行就勾“终端”或对应 App）。
3. 用手机相机扫描终端窗口里的二维码，或手动输入网址。
4. 手机页面点输入框，按手机输入法里的语音键说话。
   说完停顿一下，文字会自动出现在 Mac 当前光标处。

## 说明

- 自动发送：默认开启，适合语音输入；如果打字时也会误发，请关掉页面上的开关。
- 中文等非英文文本、多行文本会采用“剪贴板 + Cmd+V”的方式输入，会临时占用
  Mac 剪贴板（这是为了保证文字内容 100% 准确）；纯英文短文本走直接键入。
- 如果没授予辅助功能权限，文字会先进入 Mac 剪贴板，手动 Cmd+V 也能用。
- 局域网内明文传输，请只在自家 WiFi 等可信网络使用。
- 换端口：`./.venv/bin/python server.py 9000`，手机网址同步变化。
- 手机和电脑需要在同一个 WiFi/局域网内。
