# 手机语音输入 → 电脑（Windows 版）

与 Mac 版功能完全一致：手机语音说话，文字直接出现在 Windows 电脑当前光标处。
手机端不用装任何软件，扫码打开网页即可；电脑端是一个 exe。

---

## 一、系统要求

- Windows 10 或 Windows 11（64 位）。
- 如果只使用已经打包好的 exe，不需要装任何东西。
- 如果要自己打包 exe，需要 Python 3.10 或更高版本（见第三节）。
- 手机（iPhone / Android 都行）和电脑必须在**同一个 WiFi**。

---

## 二、直接使用（已打包好的 exe）

1. 双击 `语音输入电脑.exe` 启动。
2. **首次运行可能弹 SmartScreen 蓝色提示**（“Windows 已保护你的电脑”）：
   点“更多信息” → “仍要运行”。这是因为 exe 没有商业签名，
   只在自己电脑用或发给信任的朋友没问题。
3. **首次启动 Windows 防火墙会弹窗**：一定要勾选“专用网络”
   并点“允许访问”，否则手机连不上电脑。
   如果当时点错了，后面在 控制面板 → Windows Defender 防火墙 →
   允许应用或功能通过防火墙 里重新添加。
4. 手机和电脑连同一个 WiFi，用手机相机扫 App 窗口里的二维码。
5. **先在电脑上点一下要输入文字的地方**（微信、文档、浏览器、Codex 都行），
   让光标停在那里，再在手机上说话。
6. 说完停顿一下，文字自动出现在光标处。

---

## 三、自己打包 exe（build.bat）

1. 安装 Python 3.10 或更高版本，**安装时务必勾选 “Add Python to PATH”**，
   否则 `build.bat` 找不到 python。
2. 把整个项目文件夹放到一个**没有中文和空格的路径**下更稳妥
   （比如 `D:\phonevoice`），可以避免个别环境下的编码/路径问题。
3. 双击 `build.bat`。它会自动：
   - 创建 `.venv` 虚拟环境
   - 安装依赖（qrcode、pillow、pyperclip、keyboard、pyinstaller）
   - 生成图标 `app.ico`
   - 打包出 `dist\语音输入电脑.exe`
4. 打包过程中会弹出黑色命令行窗口，**不要关掉**，等它自己结束。
5. 完成后把 `dist\语音输入电脑.exe` 发给朋友即可（只发这一个文件，
   不需要带网页文件，它们已经打进 exe 里了）。

### 打包时可能遇到的问题

- **提示 “python 不是内部或外部命令”**：说明 Python 没勾选 Add to PATH，
  重装 Python 并勾选，或手动把 Python 安装目录加入系统环境变量 PATH。
- **build.bat 里的中文显示成乱码**：不影响运行，脚本逻辑不受影响。
- **杀毒软件（含 Windows Defender）拦截或删除 exe**：PyInstaller 打的包偶尔会被误报，
  在自己电脑上添加信任即可。发给朋友前建议先压缩成 zip 再传，降低误报概率。

## 四、常见问题排查

### 手机扫了码打不开页面

按顺序检查：
1. 手机和电脑是不是同一个 WiFi（连了同一个路由器）。
2. App/exe 窗口是否还开着（关掉服务就断了）。
3. 防火墙是否允许了本程序（见第二节第 3 条）。
4. 电脑如果有多个网卡（比如同时插着网线和连着 WiFi），
   App 显示的 IP 可能不是手机所在网络的那个。
   此时看 App 窗口显示的网址是不是以 `192.168.x.x` 开头；
   不对就在手机浏览器里手动输入正确网段的 IP。

### 说话后电脑没反应

1. 先确认在电脑上**点过**要输入的位置，光标在那里。
2. 文字会先进入电脑剪贴板，如果自动粘贴失败，手动 Ctrl+V 也能用。
3. 中文、多行文字用的是“剪贴板 + Ctrl+V”，会**临时占用剪贴板**，属正常现象。
4. 极少数输入法/软件会拦截模拟的 Ctrl+V，换个输入框试试。

### 端口被占用（启动即闪退/提示端口被占用）

程序默认使用 8765 端口。如果被其他程序占用：
1. 关闭占用程序，或
2. 改端口：命令行运行 `python server.py 9000`（数字随便换），
   手机端访问的网址会同步变化，二维码也会指向新端口。

### 日志在哪看

程序运行日志写在用户主目录下的 `phonevoice.log`
（一般在 `C:\Users\你的用户名\phonevoice.log`）。
排查问题时可以把最后几行发给开发者。

### 打包后换电脑运行报错

PyInstaller 打包的 exe 一般可以直接拷贝到其他 Windows 电脑运行。
如果目标电脑报缺 DLL 或杀毒拦截，把 exe 压缩成 zip 再拷贝；
仍不行就把报错信息发回来。

---

## 五、安全提示

- 手机和电脑之间在局域网内**明文传输**文字，请只在自家 WiFi 等可信网络使用。
- 同一个 WiFi 下，任何能扫到二维码的人都能向这台电脑发送文字，
  离开视线或公共网络时请退出程序。
- 本工具只模拟键盘输入，不读取、不上传任何电脑上的文件。

---

## 六、与 Mac 版的差异

- Windows 不需要“辅助功能授权”，装好打开就能用。
- 模拟输入方式不同：Windows 用“剪贴板 + Ctrl+V”，中文和多行同样可靠。
- 打包产物是 `dist\语音输入电脑.exe`，而不是 `.app`。
- 其余（手机端页面、二维码、自动发送、PWA 添加到主屏幕）与 Mac 版一致。
